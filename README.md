# 智在银河（穿戴端：腕上银河）

Android 手机应用「**智在银河**」，支持**吉利银河**及**吉利汽车、中国版领克**（见下方多品牌说明）的手机端车况读取与**米家语音直控**，也支持搭配**腕上银河**穿戴端（小米手环 10 Pro / 9 Pro / 8 Pro、小米手环 10、小米 Watch 5 或支持 Vela RPK 的圆形手表）查看车况并从穿戴端打开官方小组件对应的车控功能。

智在银河 / 腕上银河由独立开发者维护，为非官方开源辅助工具，与吉利汽车、领克、小米及米家无官方或授权关联。车主在手机端授权托管对应品牌官方中号小组件，通过本地识别与操作转交完成控车；实际车况与车控能力由官方 App、车型和车辆状态提供。

> **使用安全与免责提示**
> - 本项目按 [Apache-2.0](LICENSE)「现状」提供，不包含任何明示或默示担保；因网络/蓝牙延迟、官方卡片改版、误触或状态同步滞后造成的车辆状态差异，请以吉利银河官方 App 显示为准。
> - 开启「允许车控」后，穿戴端二次确认或米家通知指令将直接触发已绑定小组件的官方按钮。请务必为手环或手表开启**锁屏密码**，并在非本人佩戴、设备外借或长期不用时及时关闭车控授权。

## 安装与首次验证

1. 在 Android 手机上安装手机 APK。打开「智在银河」，选择车辆品牌并[绑定对应品牌的官方中号小组件](#绑定真实车况)。仅使用米家语音时，可直接按[米家语音直控](#米家语音直控)设置。
2. 使用穿戴端时，先将设备与手机配对，再按设备选择安装包。
   - **Vela 手环或手表**可通过小米运动健康中的「我的 → 关于 → Debug → 第三方应用」安装 RPK，具体取决于运动健康版本。也可使用支持该设备的 AstroBox。[小米真机安装说明](https://iot.mi.com/vela/quickapp/zh/guide/other/faq.html) · [AstroBox RPK 安装说明](https://astrobox.usea.quest/docs/quick-app-installation.html)
   - **小米 Watch 5**在手表上开启开发者选项与无线 ADB 调试，再侧载 Watch 5 APK。手表通过已配对手机的蓝牙连接伴侣 App。
3. 在手机的「穿戴设备（可选）」卡片点「启动通信」。使用小米运动健康通道时，按界面提示完成「授权小米设备通信」。使用蓝牙直连 Watch 5 时，按系统提示授予「附近设备」权限。
4. 在手环或手表的应用列表打开「腕上银河」，核对续航和更新时间。点更新时间可刷新，也可以在双屏车控页上拉后松手刷新。

三端包名均为 `com.garage.bandcontrol`。手机和 Vela 穿戴通信需要匹配的签名证书，建议使用同一发布版的安装包配对。[小米设备通信文档](https://iot.mi.com/vela/quickapp/zh/features/network/interconnect.html)

## 主题与手环布局

- 手机首页调色盘打开「手机主题」，用于手机 App 的外观。选好场景后，可以跟随手机系统深浅色、按自定义时间切换，或固定日景、夜景。
- 「穿戴设备 → 穿戴主题」单独设置下发给手环和手表的主题。选「跟随手机系统」后，穿戴端在同步车况时收到手机系统对应的日景或夜景。
- 支持本机主题的穿戴端可在「设置 → 外观主题」选择跟随手机或独立场景。Watch 5 的本机主题可以跟随手表系统，跑道小屏手环使用手机下发的穿戴主题。
- 手机的「手环布局」与支持单双屏切换的手环同步。双屏首页显示总续航、油电进度和车辆状态，第二屏显示车控。单屏纵向滚动，点车况区域可切换到油电分项。长方形和跑道屏手环的车控按钮单列排列。

## 绑定真实车况

1. 登录对应品牌的官方 App。在「智在银河」点击当前品牌的「添加中号小组件」按钮，完成 Android 绑定授权。覆盖安装时会沿用已有的第一张有效卡片。
2. 在官方小组件的配置页选中目标车辆和所需按钮。使用吉利银河时，可以点卡片右上角的齿轮进入配置。保存后回到「智在银河」，点卡片的更新时间刷新车况。
3. 中号卡片提供总续航、纯电续航（或电量百分比）、燃油续航、驻车状态和更新时间。当官方卡片仅显示电量百分比而不显示公里数时，穿戴端会自动按百分比同步展示；刷新以银河中号卡回传的数据为准，同一分钟的回传会保留原时间。卡片上的未知车控图标可直接点按补标。
4. 核对车况和按钮后，在「车控授权」里点「允许车控」。收到「指令已发送」回执后，以官方车况核对执行结果。若穿戴端提示「请在手机确认银河操作」，从「智在银河」或同名通知打开官方确认。

手机首页的「修改名称」可更改车辆名称，并同步到穿戴端。默认名称为「我的座驾」。

刷新、操作结果和连接异常以浮层短暂提示。卡片更新期间，刷新区可显示「同步中…」或「请在手机确认」。正在加载的车控按钮保留原位，状态未知时保持禁用，收到可用状态后恢复操作。

单屏手环可点状态区的齿轮进入设置，双屏从车控页底部进入「设置」。设置里可关闭默认开启的「车控震动」，也可查看最近的连接事件。[小米 Vela 振动接口](https://iot.mi.com/vela/quickapp/zh/features/system/vibrator.html)

银河的多张卡片共用一份配置，「智在银河」使用一张中号卡片。在银河「设置小组件」更换功能并保存后，穿戴端会在下一次同步时更新按钮。除霜和哨兵模式可在银河提供对应槽位时加入。

支持标记的 11 项功能为车锁、空调、车窗微开、后备箱、寻车、车窗全开、极速升温、极速降温、净化、除霜、哨兵模式。

银河 App 1.59.0 的已上锁与已解锁图标均可自动识别。卡片显示已驻车时，闭锁图标对应手环的「解锁」，开锁图标对应「上锁」。卡片显示「车门未锁」且锁图标一致时，手环显示「上锁」。点击手环车锁可直接进入对应的操作确认，车况可在时间栏单独刷新。停止穿戴通信后，已开启的车控授权保持有效，仅手环/手表侧控制需要重新启动穿戴通信。

手机 0.1.22 支持车窗、天窗、车门或后备箱未关闭提醒替代驻车文案时的车锁判断。有效车况和可识别的锁图标共同决定动作，明确行驶状态、未知状态和锁态冲突会被拦截。车锁诊断日志记录卡片原文、准备动作和锁态，便于区分状态拦截与官方回传过程。

车窗结合官方卡片的当前车况和槽内图标判断方向。车窗关闭时提供「窗微开」或「窗全开」。卡片显示「车窗未关」时，已开启的车窗槽提供「关窗」，另一槽等待状态恢复。车况与图标冲突、缺少有效读数或无法识别开关方向时，按钮显示暂不可用。

空调、净化、极速升温、极速降温、除霜和哨兵模式按当前官方按钮的图标切换开关文案，例如「开空调／关空调」「开净化／关净化」。确认页显示完整动作，例如「关闭极速降温」。手环把显示的方向带入确认请求，手机在准备和执行时核对当前槽位、图标指纹及方向，状态变化后需重新选择。寻车和后备箱继续使用对应的官方按钮。具体车型的组件远程关后备箱及支持的功能槽位以吉利银河官方配置为准。

[Android 小组件托管文档](https://developer.android.com/develop/ui/views/appwidgets/host) · [银河中号卡片的社区接入记录](https://github.com/yangyongyongyong/GeelyPassiveKey/blob/main/docs/79_official_widget_fallback.md)

## 米家语音直控

1. 在手机首页「米家语音」点「通知权限」，为「智在银河」授予通知使用权，再打开「米家语音」开关。开关默认关闭。
2. 在米家创建手动场景「银河车况测试」，动作选「手机通知」，内容填写 `GARAGE_V1:TEST`。用小爱触发后，在手机 App 查看测试通知是否命中。吉利汽车和领克可在首页「指令码」查看对应品牌的测试码。
3. 核对官方卡片和车辆后，在手机 App 点「允许车控」。通过「指令码」复制所需动作的指令，在米家创建对应的手机通知场景。仅用语音时可跳过穿戴通信。
4. 用小爱触发场景。伴侣 App 在后台也可接收通知并直接转交当前银河中号卡片对应的按钮，手环可停留在小爱页面。若银河卡片显示官方确认，伴侣 App 会提示到手机处理。

| 动作 | 米家手机通知内容 |
| --- | --- |
| 上锁 | `GARAGE_V1:LOCK` |
| 解锁 | `GARAGE_V1:UNLOCK` |
| 空调 | `GARAGE_V1:CLIMATE` |
| 车窗微开 | `GARAGE_V1:WINDOW_VENT` |
| 后备箱 | `GARAGE_V1:TRUNK` |
| 寻车 | `GARAGE_V1:FIND` |
| 车窗全开 | `GARAGE_V1:WINDOW_OPEN` |
| 极速升温 | `GARAGE_V1:HEAT` |
| 极速降温 | `GARAGE_V1:COOL` |
| 净化 | `GARAGE_V1:PURIFY` |
| 除霜 | `GARAGE_V1:DEFROST` |
| 哨兵模式 | `GARAGE_V1:SENTRY` |

11 项功能共用当前卡片的四个槽位。上锁与解锁分别核对卡片锁态和按钮方向。「车窗微开」和「车窗全开」码只允许开启方向，当前槽显示关窗时会拒绝。空调、净化、极速升降温、除霜和哨兵码调用卡片当前方向的按钮，场景应按功能命名，例如「银河空调」「银河净化」。手机语音结果的「已发送命令」表示已转交银河，车辆结果以官方车况为准。

[米家通知来源包名](https://app.mi.com/details?id=com.xiaomi.smarthome) · [Android 通知监听](https://developer.android.com/reference/android/service/notification/NotificationListenerService)

## 后台运行

「后台运行设置」在手机首页的「穿戴设备」上方。打开「省电策略设置」，可跳转到应用信息或 Android 电池优化列表。在应用信息的电池设置中选择「无限制」或开启「允许后台活动」，也可在电池优化列表将「智在银河」设为「不优化」。返回应用会重读 Android 电池优化状态。

「应用锁定引导」说明如何在最近任务里锁定「智在银河」。部分小米手机可在「手机管家 → 设置 → 优化加速 → 锁定任务」中开启。系统提供的入口随手机型号和系统版本变化。

[Android 电池优化](https://developer.android.com/training/monitoring-device-state/doze-standby) · [小米应用智能省电](https://dev.mi.com/distribute/doc/details?pId=1628) · [小米后台应用锁定](https://www.mi.com/global/support/faq/details/KA-535435/)

## 本地构建

需要 Windows、JDK 17 或 21、Android SDK Platform 36、Node.js 与 npm，以及 OpenSSL（可用 Git for Windows 自带版本）。配置好 `ANDROID_HOME` 或 Android Studio 的 SDK 路径，在项目根目录运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\build.ps1
```

脚本从小米官方样例取得固定版本的 Wearable SDK，校验 SHA-256，生成本地签名，运行 Android 单测与手环通信回归测试，再输出配套 APK 和 RPK。首次构建会下载 Gradle 和 npm 依赖。后续更新请保留 `.local` 中的签名文件，以便覆盖安装并保持两端证书一致。私钥、口令和构建缓存收在 Git 忽略的目录中。

[小米 SDK 与样例下载入口](https://iot.mi.com/vela/quickapp/zh/features/network/interconnect.html)

## 手机端运行日志

伴侣在页面内容底部的「运行日志」集中展示连接变化、通知接收、车控授权、刷新结果和操作提示；0.1.33 起日志区域支持固定高度内独立滚动，便于查看历史记录。最新记录突出显示，异常以琥珀色区分，记录带时间并可清空。最近 40 条保存到本机，重启后可查看。手环区域显示简短连接与授权状态，米家语音使用开关，后台运行设置收为可展开的入口。

## 多品牌适配（0.1.30 – 0.1.33）

同一个伴侣 App 与穿戴包支持**银河**、**吉利汽车**（0.1.32+）和**中国版领克**（0.1.30+），包名仍为 `com.garage.bandcontrol`。全新安装可选择品牌；已有银河卡片自动迁移银河。首页「车辆品牌」可切换，切换后请核对或重新绑定对应品牌官方小组件，再开启车控授权；语音开关会关闭，需要重新开启。原品牌卡片配置保留，品牌间独立存储。

**吉利汽车**：适配「吉利汽车」App 3.58.0 官方中号小组件，首版识别车锁、空调和寻车，米家语音使用独立指令码 `GEELY_V1:TEST`、`LOCK`、`UNLOCK`、`CLIMATE`、`FIND`，具体车型及可选按钮以官方卡片实际显示为准。详情见 [吉利汽车 3.58.0 调研](docs/geely-auto-3.58.0-integration-review.md)。

**领克（0.1.33）**：领克 4.2.9 的桌面中型小组件提供三个可配置位置。伴侣显示当前实际同步数量，扫描时仍兼容布局中的隐藏节点。伴侣可按控件描述或已安装领克 App 的官方图标轮廓自动识别**车锁、车窗、后备箱、寻车、发动机、天窗、快速升温、快速降温、充电口**（手动标记另支持区分车窗微开/全开），并同步短名称及与银河同风格的图标至手环和手表端。识别为车锁、车窗或后备箱的按钮可在穿戴端直接确认切换，无需预先标记方向；伴侣会且仅会自动提交紧随本次派发后 5 秒内、出现在同一卡片上且标题与本次动作（已核对锁窗或自动识别的车锁/车窗/后备箱切换）匹配的官方确认，无法自动关联时会在手机日志记录原因，其他弹窗仍需在手机处理。

银河使用原 `GARAGE_V1` 米家通知码；吉利汽车使用 `GEELY_V1`。领克的 `LYNKCO_V1:WINDOW_TOGGLE` 和 `LYNKCO_V1:LOCK_TOGGLE` 会点击官方卡片上唯一能识别的对应按钮，无需预先标记方向（若卡片有多个同类按钮，则提示改在穿戴端选择）。明确的开窗、关窗及锁车指令仍需核对按钮功能和方向，后备箱等其余功能暂不开放领克语音直发。开启车控授权与米家语音后，通过检查的命令由手机直接派发，无需连接穿戴设备。领克指令完整列表见 [领克语音](docs/lynkco/voice.md)。
