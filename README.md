# 智在银河（穿戴端：腕上银河）

Android 手机应用「**智在银河**」，支持**所有吉利银河车型**的手机端车况读取与**语音直控**（小米米家 / OPPO 小布指令），也支持搭配**腕上银河**穿戴端（小米手环 10 Pro / 9 Pro / 8 Pro、小米手环 10、小米 Watch 5 或支持 Vela RPK 的圆形手表）查看车况并从穿戴端打开官方小组件对应的车控功能。

智在银河 / 腕上银河由独立开发者维护，为非官方开源辅助工具，与吉利汽车、小米、米家及 OPPO 无官方或授权关联。车主在手机端授权托管银河官方中号小组件，通过本地识别与操作转交完成控车；实际车况与车控能力由官方 App、车型和车辆状态提供。

> - 开启「允许车控」后，穿戴端二次确认或来自米家 / 小布指令的通知指令将直接触发已绑定小组件的官方按钮。请务必为手环或手表开启**锁屏密码**，并在非本人佩戴、设备外借或长期不用时及时关闭车控授权。

手机端「智在银河」0.1.29（versionCode 30）已将**车控授权 / 语音直控**与**穿戴设备连接**解耦：无手环/手表的用户可直接绑定卡片并开启「允许车控」搭配米家或 OPPO 小布指令语音使用，也可按需搭配穿戴端「腕上银河」Vela RPK 0.1.29（versionCode 30）或手表端 APK 0.1.29（versionCode 30），均支持覆盖安装。手机首页用一张银河官方中号卡片展示车况，「车控授权」「语音直控」「穿戴设备（可选）」三张卡片各自独立控制，并支持在手机端自定义车辆名称（默认「我的座驾」）同步到穿戴端。穿戴端默认并排或纵向展示纯电（公里数或电量百分比）和燃油续航，点车况卡片可切换总续航，并按官方卡片的槽位顺序同步已识别的车控按钮。

## 安装与首次验证

1. 在手机上安装 `artifacts/galaxy-band-companion.apk`。保持手机蓝牙已开启，与手环或手表保持配对。
2. 穿戴端按设备系统二选一安装：
   - **小米手环 10 Pro（336×480）/ 小米手环 10（212×520 跑道屏）/ 支持 Vela RPK 的圆形手表（480×480）**：安装 `artifacts/galaxy-band.rpk`。若小米运动健康提供调试安装入口，可用「我的 → 关于 → Debug → 第三方应用」，也可对照 AstroBox 的 RPK 安装文档。应用会通过 `@system.device` 自动识别跑道窄屏（单列滚动）、矩形屏和圆形表盘安全区。
   - **小米 Watch 5（Android / Wear OS 侧载 APK 路线）**：在手表开启开发者选项与无线 ADB 调试后安装 `artifacts/galaxy-watch-companion.apk`。手表端通过已配对手机的蓝牙 RFCOMM（SPP）通道直接连接手机伴侣 App。
3. 打开手机的「智在银河」，按下方步骤绑定银河官方中号小组件。如仅使用语音控车（米家或 OPPO 小布指令），直接开启「允许车控」与「语音直控」即可（无需启动穿戴通信或授予蓝牙权限）；如需搭配手环或手表，再在「穿戴设备（可选）」卡片点击「启动通信」。使用小米运动健康通道出现「授权小米设备通信」时按界面确认；使用蓝牙直连手表时确认已授予「附近设备」权限。
4. 从手环或手表应用列表打开「腕上银河」，核对续航和更新时间。点更新时间或旁边的刷新图标可以刷新车况。

[小米真机安装说明](https://iot.mi.com/vela/quickapp/zh/guide/other/faq.html) · [AstroBox RPK 安装说明](https://astrobox.usea.quest/docs/quick-app-installation.html)

安装 APK 和 RPK 可使用完整的车控进度提示。开发包的包名都是 `com.garage.bandcontrol`，两端使用同一证书。

[小米设备通信文档](https://iot.mi.com/vela/quickapp/zh/features/network/interconnect.html)

## 绑定真实车况

1. 在「智在银河」点击「添加银河中号小组件」，完成 Android 的绑定授权。吉利银河 App 需要已登录。覆盖安装时会沿用已有的第一张有效卡片。
2. 点卡片右上角的齿轮，在吉利银河里选中目标车辆并设置四个按钮。首次设置时可以直接点官方卡片进入引导。保存后回到「智在银河」，点卡片的更新时间可刷新车况。
3. 中号卡片提供总续航、纯电续航（或电量百分比）、燃油续航、驻车状态和更新时间。当官方卡片仅显示电量百分比而不显示公里数时，穿戴端会自动按百分比同步展示；刷新以银河中号卡回传的数据为准，同一分钟的回传会保留原时间。卡片上的未知车控图标可直接点按补标。
4. 车况和按钮都确认后，点「允许车控」（可单独用于语音直控，也可搭配穿戴端通信；停止穿戴通信不再自动关闭车控授权）。手环/手表确认后立即返回首页。收到「指令已发送」后，可从车况判断执行结果。若手环提示「请在手机确认银河操作」，从「智在银河」或同名通知打开官方确认。

刷新、操作结果和连接异常以浮层短暂提示。手环状态栏显示更新时间和连接状态，点左侧可刷新。银河卡片更新期间，刷新区显示「同步中…」或「请在手机确认」，点按可立即读取状态。正在加载的车控按钮保留原位，在卡片恢复后自动变为可用。

点状态栏右侧的齿轮进入「设置」。这里可关闭默认开启的「车控震动」，也可查看最近三条连接事件。点选车控、点确认、收到「指令已发送」回执时各短震一次。车控失败、拒绝或超时时双短震。确认框弹出、轮询和切换页面保持安静。真机验证时请确认当前手环固件可调用震动接口。 [小米 Vela 振动接口](https://iot.mi.com/vela/quickapp/zh/features/system/vibrator.html)

银河的多张卡片共用一份配置，「智在银河」使用一张中号卡片。在银河「设置小组件」更换功能并保存后，穿戴端会在下一次同步时更新按钮。除霜和哨兵模式可在银河提供对应槽位时加入。

支持标记的 11 项功能为车锁、空调、车窗微开、后备箱、寻车、车窗全开、极速升温、极速降温、净化、除霜、哨兵模式。

银河 App 1.59.0 的已上锁与已解锁图标均可自动识别。卡片显示已驻车时，闭锁图标对应手环的「解锁」，开锁图标对应「上锁」。卡片显示「车门未锁」且锁图标一致时，手环显示「上锁」。点击手环车锁可直接进入对应的操作确认，车况可在时间栏单独刷新。停止穿戴通信后，已开启的车控授权保持有效，仅手环/手表侧控制需要重新启动穿戴通信。

手机 0.1.22 支持车窗、天窗、车门或后备箱未关闭提醒替代驻车文案时的车锁判断。有效车况和可识别的锁图标共同决定动作，明确行驶状态、未知状态和锁态冲突会被拦截。车锁诊断日志记录卡片原文、准备动作和锁态，便于区分状态拦截与官方回传过程。

车窗结合官方卡片的当前车况和槽内图标判断方向。车窗关闭时提供「窗微开」或「窗全开」。卡片显示「车窗未关」时，已开启的车窗槽提供「关窗」，另一槽等待状态恢复。车况与图标冲突、缺少有效读数或无法识别开关方向时，按钮显示暂不可用。

空调、净化、极速升温、极速降温、除霜和哨兵模式按当前官方按钮的图标切换开关文案，例如「开空调／关空调」「开净化／关净化」。确认页显示完整动作，例如「关闭极速降温」。手环把显示的方向带入确认请求，手机在准备和执行时核对当前槽位、图标指纹及方向，状态变化后需重新选择。寻车和后备箱继续使用对应的官方按钮。具体车型的组件远程关后备箱及支持的功能槽位以吉利银河官方配置为准。

[Android 小组件托管文档](https://developer.android.com/develop/ui/views/appwidgets/host) · [银河中号卡片的社区接入记录](https://github.com/yangyongyongyong/GeelyPassiveKey/blob/main/docs/79_official_widget_fallback.md)

## 语音直控（米家 / OPPO 小布指令）

支持两个系统级通知来源包名，开关默认关闭，均在伴侣 App「语音直控」卡片管理：
- **小米 / 通用（米家）**：来源包名 `com.xiaomi.smarthome`，通过米家手动场景「手机通知」触发。
- **OPPO / 一加（ColorOS 小布指令，旧名 Breeno 指令）**：来源包名 `com.coloros.shortcuts`（注意不是小布助手 `com.heytap.speechassist`），通过小布指令「发送提醒」动作触发。

1. 在「智在银河」首页的「语音直控」卡片点「通知权限」，为「智在银河」开启通知使用权，再打开「语音直控」开关。
   - **OPPO / 一加（ColorOS 13 及以上）提示**：本地侧载安装 APK 后，通知使用权开关可能因「受限制的设置」呈灰色。请先到「系统设置 → 应用 → 应用管理 → 智在银河 → 右上角菜单 → 允许受限制的设置」验证解锁，再返回开启通知权限。
2. 先测试通知链路（无需触发实际车控）：
   - **米家**：创建手动场景「银河车况测试」，动作选「手机通知」，内容填写 `GARAGE_V1:TEST`，用小爱触发或手动执行。
   - **OPPO 小布指令**：打开「小布指令（原 Breeno 指令）」App，新建指令并添加「发送提醒」动作，提醒内容仅填写 `GARAGE_V1:TEST`（可设置语音口令触发），执行后「智在银河」运行日志应显示「小布指令通知已接收 / 通知测试通过」及命中的通知字段。
3. 开启「允许车控」后，为需要的动作分别创建场景或小布指令，通知/提醒内容填写下方对应指令码（也可在 App 内点「指令码」一键复制）。
4. 用小爱或小布语音触发后，「智在银河」在后台即可接收通知并直接转交当前银河中号卡片对应的按钮。若银河卡片弹出官方二次确认，「智在银河」会提示到手机处理。

| 动作 | 通知 / 提醒内容指令码 |
| --- | --- |
| 上锁 | `GARAGE_V1:LOCK` |
| 解锁 | `GARAGE_V1:UNLOCK` |
| 空调 | `GARAGE_V1:CLIMATE` |
| 车窗微开 | `GARAGE_V1:WINDOW_VENT` |
| 后备箱 | `GARAGE_V1:TRUNK` |
| 寻车 | `GARAGE_V1:FIND` |
| 车窗全开 | `GARAGE_V1:WINDOW_OPEN` |
| 极速升温 | `GARAGE_V1:HEAT` |
| 极速降温 | `GARAGE_V1:COOL` |
| 净化 | `GARAGE_V1:PURIFY` |
| 除霜 | `GARAGE_V1:DEFROST` |
| 哨兵模式 | `GARAGE_V1:SENTRY` |

11 项功能共用当前卡片的四个槽位。上锁与解锁分别核对卡片锁态和按钮方向。「车窗微开」和「车窗全开」码只允许开启方向，当前槽显示关窗时会拒绝。空调、净化、极速升降温、除霜和哨兵码调用卡片当前方向的按钮，场景或指令应按功能命名，例如「银河空调」「银河净化」。手机语音结果的「已发送命令」表示已转交银河，车辆结果以官方车况为准。

## 后台运行

在手机首页找到「后台运行设置」。打开「省电策略设置」，可跳转到应用信息或 Android 电池优化列表。在应用信息的电池设置中选择「无限制」或开启「允许后台活动」，也可在电池优化列表将「智在银河」设为「不优化」。OPPO / 一加（ColorOS）请在「应用信息 → 耗电管理」开启「允许完全后台行为」与「允许自启动」。返回应用会重读 Android 电池优化状态。

「应用锁定引导」说明如何在最近任务里锁定「智在银河」。部分小米手机可在「手机管家 → 设置 → 优化加速 → 锁定任务」中开启，ColorOS 可在最近任务卡片菜单直接锁定。系统提供的入口随手机型号和系统版本变化。

[Android 电池优化](https://developer.android.com/training/monitoring-device-state/doze-standby) · [小米应用智能省电](https://dev.mi.com/distribute/doc/details?pId=1628) · [小米后台应用锁定](https://www.mi.com/global/support/faq/details/KA-535435/)

## 本地构建

需要 Windows、JDK 17 或 21、Android SDK Platform 36、Node.js 与 npm，以及 OpenSSL（可用 Git for Windows 自带版本）。配置好 `ANDROID_HOME` 或 Android Studio 的 SDK 路径，在项目根目录运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\build.ps1
```

脚本从小米官方样例取得固定版本的 Wearable SDK，校验 SHA-256，生成本地签名，运行 Android 单测与手环通信回归测试，再输出配套 APK 和 RPK。首次构建会下载 Gradle 和 npm 依赖。后续更新请保留 `.local` 中的签名文件，以便覆盖安装并保持两端证书一致。私钥、口令和构建缓存收在 Git 忽略的目录中。

[小米 SDK 与样例下载入口](https://iot.mi.com/vela/quickapp/zh/features/network/interconnect.html)
