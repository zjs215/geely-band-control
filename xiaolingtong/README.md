# 小领通

独立的 Android 手机伴侣，可搭配支持 APK 安装的 Android 手表或小米 Vela 穿戴设备。手机伴侣为 0.3.62，Watch 为 0.3.42，Vela 穿戴端为 0.2.34。车辆数据来自中国版领克 App 4.3.1 的官方中号卡片。手表和手环首页底部的「刷新车况」会显示上次更新时间，点整行即可刷新。

手机 APK 与 Vela RPK 的包名均为 `com.mario.lynkband.phone`。从旧包名切换时，先暂停旧手机伴侣的后台通信，首次打开新版后重新绑定卡片、选择手表并授权。在 Vela 手环上请安装配套 RPK。[小米设备通信说明](https://iot.mi.com/vela/quickapp/zh/features/network/interconnect.html)

手机、Android Watch 和标准屏 Vela 只有「蓝天与星空」是内置主题。在手机的「外观 → 主题 → 在线主题」选择主题后，手机校验日景和夜景后保存一份本地副本，可在「主题」列表离线重选或删除。在线列表仅显示未下载或有更新的主题。每项显示版本，有更新时还会显示「更新」。删除当前主题会恢复默认主题。打开「同步主题到穿戴设备」后，已连接的设备会自动接收该设备尺寸的两张图，只保留当前主题。标准屏 Vela 应用打开时，收到手机的主题变更通知会自动同步。传输中断时继续用原主题，重连后重新同步。关闭同步后，穿戴端下次连接时恢复默认主题。胶囊屏 Vela 使用纯色单列布局，提供车况和车控，省去车图和主题资源。

主题从 CNB 仓库的 `themes/` 下载，GitHub 的 `xiaolingtong/themes/` 提供备用下载。新增主题时，参照 `themes/catalog.json` 添加条目，放入 `phone-day.webp`、`watch-day.webp`、`watch-night.webp`、`vela-day.png` 和 `vela-night.png`，填写各图的 SHA-256。首次发布让 `version` 为 1，主题资源更新时递增。手机夜景复用 Watch 夜景。WebP 每张最多 256 KiB、边长最多 1600 像素，Vela PNG 每张最多 48 KiB、边长最多 512 像素。两处发布相同的目录和图片后，手机重新打开主题列表即可看到。已支持在线主题的设备可直接同步。

在 Watch 的「设置 → 主题和昼夜 → 日出日落」或标准屏 Vela 的「设置 → 昼夜」选择「跟随手机」或「用户设定」。跟随手机时使用手机的切换时间。离线时使用本机保存的时间，默认 06:00 和 18:00。手机可以使用大致位置估算日出日落。

## 升级后主题显示

手机升级时会保留当前主题和导入的主题。此前只保存当前下载主题的版本会把这份图片加入本地列表。更早的版本会保留预设选择，缺图时先显示默认主题，在联网后恢复原预设。旧版切换主题后已移除的图片可以在「在线主题」重新下载。

新版手机向旧穿戴端发送可识别的预设名称。同名预设会使用旧端内置的版本，自定义主题会显示默认主题。旧手机连接新版穿戴时，同名缓存可以继续显示。缓存缺失时先显示默认主题，连接支持主题图片同步的手机后可获取资源。主题资源与车况分别传输。

九套在线主题已升级为 v3。手机、Android Watch 和 Vela 标准屏支持主题专属动效，例如摇曳营火、翻折棱镜、带叶脉的竹叶、电路走线和猫爪印。更新对应设备的安装包后即可使用新动效，已有主题可以继续使用。穿戴端缺少车辆照片时会显示默认领克 07 EM-P，收到照片后替换。REDMI Watch 4 的背景使用独立图片层按屏幕尺寸铺满。设备规格和测试范围见 [设备适配表](docs/穿戴设备适配.md)。

新增折角构成、磁带纪元、仓鼠邮差和珐琅流沙 v1。每套包含日夜图和专属动效，可在线下载或导入主题 ZIP。

## 导入本地主题包

在手机的「外观 → 主题 → 导入主题包」选择小领通主题 ZIP。校验通过后自动应用，之后可在「主题」列表离线重选。同一主题 ID 再次导入会更新手机保存的副本。已开启穿戴主题同步时，选择的本地主题也会同步到 Watch 和标准屏 Vela。

主题 ZIP 上限为 1 MiB，根目录包含 `theme.json` 和上文的五张图片。`theme.json` 使用 UTF-8，包含 `schema`（整数 1）、`id`、`title`、`version` 和 `assets`。主题版本号为正整数，旧包未填写时按 v1 读取。`assets` 的键为不带扩展名的图片名，值为对应文件的 64 位十六进制 SHA-256。`id` 使用 1 至 32 位小写英文字母、数字或连字符，以字母或数字开头，默认主题保留 `sky`。名称最多 32 字。可把在线目录中某个主题的条目加上 `schema` 字段，作为 `theme.json`，再与五张图片一起压缩。

## 更新手机应用

手机底部的「应用」可开启「在最近任务中隐藏」，之后可从桌面打开小领通。同一区域的「检查手机应用更新」优先从 CNB 查询和下载手机 APK、Watch APK 和两种 Vela RPK，GitHub Releases 提供备用版本和文件。手机更新校验文件、签名和版本后，由系统确认安装。首次使用时按 Android 提示允许小领通安装更新。较早版本可从发布页下载安装过渡版。 [CNB](https://cnb.cool/sidabakesi/xiaolingtong) · [GitHub Releases](https://github.com/chashaobao/geely-band-control/releases?q=xiaolingtong)

发布时将四个签名安装包和 `SHA256SUMS.txt` 放入 CNB 的 `downloads/<发布标签>/`，并将同样的文件附到 GitHub 的同名 Release。CNB 的 `downloads/releases.json` 使用 `{"schema":1,"releases":[...]}`，每条发布记录包含 `tag` 和四个 `assets`。每个文件记录 `name`、字节数 `size` 和 `sha256`。安装包两边都可下载后再更新索引。

## 在手机上选择控制项目

绑定官方中号卡片后，在「控制项」找到卡片对应的按钮，点「编辑」并选择按钮类型。每个按钮只需选一个项目，例如「车窗」「空调」或「车锁」。选「不选择（清除）」可清除该按钮的选择。Watch 5 和 Vela 手环共用这项设置。

手机在项目名后显示官方卡片的当前状态。例如「车窗.开」表示卡片显示车窗已开，「车窗.关」表示已关。卡片正在加载时显示「车窗.加载」，无法识别状态时显示「车窗.未知」。这两种状态下仍可选择或更换项目。选择项目只更新设置，不会触发车控。

## Android 手表（Watch APK）

1. 手机安装或覆盖更新 `artifacts/lynk-companion-phone.apk`，登录领克官方 App，打开「小领通」会自动绑定领克中号卡片。首次遇到 Android 授权提示时点允许，已有绑定直接复用。
2. 在支持安装 Android 应用的 Watch 5 固件上安装 `artifacts/lynk-watch.apk`（手表端包名 `com.mario.lynkband.watch`）。若手表开放无线调试，可用 Android 平台工具选择手表后执行 `adb -s <手表设备号> install -r artifacts/lynk-watch.apk`。
3. 手机和手表先完成系统蓝牙配对。在手机伴侣选择「android」，点「选择手表」选中自己的手表。手机自动启动穿戴通信。打开手表上的「小领通」，点「选择手机」选中同一台手机，按提示授予附近设备权限。手机选择 Watch 5 后，首页显示手表通信状态。选择「Vela」可切换到小米运动健康通信，保留已配对手表供下次切回。
4. 手表首页显示续航、电量、油量和连接状态。官方中号卡片加载车辆图片后，手表会在当前日景或夜景中放大显示车模。上滑或转动表冠可看到半透明玻璃车控按钮和官方更新时间。图片变化时通过已配对的蓝牙连接同步，缺图时按钮自动上移。首页按官方卡片顺序最多显示四个按钮。长方屏、跑道屏和小屏每行一项，宽度足够的圆屏和方屏每行两项。首页和确认页按按钮类别及状态显示手表内置的官方图标。手机伴侣 0.3.38 与 Watch 5 端 0.3.29 配套使用时，蓝牙车况回复只传输按钮资料和状态。绿色表示开，默认色表示关，黄色脉冲表示加载，灰色表示未知。点按可用按钮后，在手表上核对将要执行的动作并确认。点击更新时间可刷新。所选的已配对手表自动获得车控权限。车况只读时，手表隐藏所有车控按钮。
5. 小米手机请在「小领通 → 锁屏连接设置 → 打开应用信息 → 省电策略」选择「无限制」。系统冻结进程时，常驻通知可能仍在，手表要等到手机解冻才能连接。手表应用打开时，连接中断会立即重试，连续失败后间隔逐步增加到 16 秒。重连只同步状态，待确认或已发出的操作不会重放。此版本通过已配对的蓝牙 RFCOMM 连接手机。两台设备须在蓝牙范围内，手机伴侣的穿戴通信服务须运行。eSIM 或手表 Wi-Fi 无法替代该连接。手机能否远程控车由领克官方 App 和车辆状态决定。

## 从手机更新 Android 手表

1. 首次通过 ADB 安装带「接收手机更新」入口的手表 APK，并确认手机伴侣中的 Android 穿戴通信已开启。
2. 在手机「设备」中选 Android，再点「穿戴端更新」，选择本地文件或发布版本。点「开始准备」，等手机显示正在等待手表接收。
3. 在手表的「设置」点「接收手机更新」，保持两端更新页面打开。手表校验包名、签名、版本和 SHA-256，通过后提示「手表更新已就绪」。
4. 在手表点「安装」，按系统提示允许从小领通安装并确认。第一次授权后，返回小领通继续安装。安装完成后可在手表设置底部核对版本号。

手机的「安装包已发送」表示手表已校验并保存文件。只接受同签名 APK，按 versionCode 允许同版本覆盖或更高版本升级。传输中断后重新开始发送；已校验的文件可选「稍后」，再从接收入口继续安装。

## 小米 Vela 穿戴端（RPK）

1. 在 Android 9 或以上的手机安装 `artifacts/lynk-companion-phone.apk`。先登录领克官方 App，确认能看到自己的车辆。小米运动健康应已和手环配对。
2. 按屏形选一个 RPK。两端呈半圆的跑道屏（如小米手环 9）选 `lynk-band-pill-0.2.24.rpk`。圆屏、长方屏、正方屏（如小米手环 10 Pro）选 `lynk-band-standard-0.2.24.rpk`。使用固件提供的第三方应用安装入口或兼容的 RPK 安装工具。手机 APK 和手环 RPK 需要来自同一套签名。
3. 在「小领通」点「绑定领克中号卡片」，通过 Android 的创建小组件授权。官方卡片出现后，核对车辆、续航、电量、油量和更新时间。展示内容取决于车型和卡片的当前状态。
4. 在手机选择「Vela」，按提示授予附近设备权限。若出现「授权 Vela 手环通信」，点按并在小米运动健康完成授权。打开手环上的「小领通」查看车况，点更新时间或「刷新车况」可请求官方卡片更新。
5. 在手机为卡片按钮选择控制项目后，已在小米运动健康配对并授权的手环重连即可使用。RPK 首页根据屏形和宽度排列卡片按钮。长方屏、跑道屏和窄小屏幕显示单列，宽度足够的圆屏和方屏显示两列。点按可用按钮，在手环核对将要执行的动作并确认。
6. Android Watch 和标准屏 Vela 在车况与车控按钮之间显示车图，缺图时显示内置的领克车图，胶囊屏使用纯色单列车控首页。手表能排两列且有至少两个车控按钮时，可在设置中切换列表或网格。网格最后一排的单个按钮居中。标准屏和跑道屏都使用安装包内的领克 4.3.1 官方图标，按手机配置的按钮类别和当前状态显示。
7. 「已转交领克卡片」表示伴侣已触发官方按钮。可持续读取开关状态的动作会等待车况确认，无法确认时提示查看官方车况。停止通信或断开设备会清除待执行指令。更换车辆、重新绑定卡片或调整官方按钮后，请在手机核对各按钮对应的控制项目。

在手机「设备 → Vela → 穿戴端更新」选择标准屏或胶囊屏的在线或本地 RPK。点「蓝牙安装」，选择已配对的设备或附近广播小米 BLE 服务的设备。首次连接输入该设备的 AuthKey。认证成功后，AuthKey 会按蓝牙地址用 Android Keystore 加密保存，后续安装可直接复用，也可在安装弹窗中清除。默认按蓝牙类型和串口握手应答选择协议，经典蓝牙可用 SPP V2 或兼容 SPP V1，低功耗蓝牙可用 BLE V2。串口握手无法识别版本且 V2 会话不可用时，自动重连尝试 SPP V1，也可以手动指定。安装前核对设备应用列表，允许首次安装、同版本覆盖和升级。也可以「保存 RPK」后交给其他安装工具。

Android 手表首次安装时，在「穿戴端更新」选好 Watch APK，点「首次安装 · ADB」。手机和手表连同一 Wi-Fi，先输入手表无线调试配对弹窗的地址和六位码，再输入无线调试主页的连接地址。手机检查手表的应用列表，仅在尚未安装小领通时发送 APK 并核对版本。已安装的手表继续使用「蓝牙更新」和手表上的「接收手机更新」。

## 小爱语音车控
在手机「米家语音车控」开启语音并授予通知使用权。需保持后台通信运行。先在「手表上的车控」为卡片按钮选择对应项目，例如为车锁按钮选择「车锁」。再点「配置米家场景」，从七类 14 项语音预设中选择要执行的动作，例如「上锁」。核对「已匹配卡片」等状态，在详情点「复制指令并打开米家」。在米家为每条指令创建手动场景，动作选「手机通知」。例如「领克上锁」发送 `LYNK:动作:上锁`，默认说出场景名就会转交当前领克卡片。若在伴侣开启「语音执行前再次确认」，再建一个名为「确认」的场景，发送 `LYNK:确认`。先让小爱运行「领克上锁」，15 秒内再说“确认”，手机重新核对同一个卡片按钮后执行。语音触发后，伴侣会等待同一张卡片的匹配问句。即使车窗按钮先显示进度圈，只要「确认打开车窗吗？」在 6 秒内出现，也会点击一次「确定」。可用 `LYNK:测试` 核对通知链路，或用 `LYNK:取消` 取消待执行动作。手机通知和伴侣页面显示回执。

## 构建

Windows、JDK 17 或 21、Android SDK Platform 36、Node.js / npm、Git for Windows 或 OpenSSL。设置 `JAVA_HOME` 和 `ANDROID_HOME`，在项目根目录运行：

```powershell
.\scripts\build.ps1
```

构建脚本从小米官方样例下载指定版本的通信 SDK，校验哈希，以同一证书生成两个 release APK 和两种屏型的 release RPK，运行手机和 Watch 5 单测、Android lint 和已编译手环页面的协议测试。产物和 SHA-256 校验文件在 `artifacts/`，签名别名为 `mario`。下载用 APK 的文件名包含各自的版本号，固定文件名仍供旧版在线更新使用。首次构建请通过环境变量 `LYNK_SIGNING_PASSWORD` 提供密钥库密码。备份本机 `.local/mario/`，后续构建复用它。曾在本机构建旧版时会沿用原证书，以支持覆盖安装。依赖与授权说明见 [NOTICE](NOTICE) 和 [LICENSE](LICENSE)。

## 实现和验证边界

- Android 使用系统 AppWidgetHost 托管车主授权的官方中号卡片。从当前可见的控件同步数据，保留官方更新时间和原始单位。后台通信由前台服务维持。已配置的手机在允许的条件下会在重启解锁或应用更新后恢复通信。
- Vela 手环使用小米 interconnect，Watch 5 使用加密的经典蓝牙 RFCOMM。确认票限设备、目标和本次授权，有效期 15 秒且只能使用一次。手环退出确认页、通信中断或状态变化后可重新选择动作。在穿戴端确认动作后，如果同一张卡片在 6 秒内显示匹配的普通车控提示（例如「确认打开车窗吗？」），手机伴侣会点击「确定」。提示不匹配时请在手机处理。收到「已点卡片确定」后，可在官方卡片核对车辆状态。
- 模拟器上的官方卡片测试需要安装中国版领克 4.3.1。Android 仪器测试在本地渲染已安装包的真实布局并填入模拟读数和本地点击监听。可对指定测试设备运行 `android/gradlew.bat -p android :app:connectedDebugAndroidTest`（仅连接目标测试设备时使用）。
- 小米运动健康配对、真实车况更新、后台保活和各车型车控需用车主账号及实际设备验证。

0.1.0 已在 Android 11 模拟器上通过系统授权绑定领克 4.3.1 官方中号卡片，重启后恢复绑定并显示官方未登录提示。7 项 Android 单测、4 项官方卡片布局设备测试和 7 项编译后手环协议测试通过。配套安装包已核对包名、版本、签名证书和校验值。
