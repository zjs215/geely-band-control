# 小米穿戴屏幕与小领通安装方式

分辨率是设备规格。小领通按运行时上报的屏幕尺寸和屏形缩放界面。固件漏报屏形时保留安全边距，漏报尺寸时仍可打开车况页面。能否安装和通信取决于固件支持的应用平台与接口。

标准屏用独立图片层铺满背景，前台主页播放轻量动效，缺少车辆照片时显示默认领克 07。圆屏使用内收的车况区，窄矩形用单列。胶囊屏使用单列纯色车况与车控。

REDMI Watch 4 的原生分辨率为 390×450。小米文档列出该型号的 CSS 背景缩放限制。应用使用独立图片层绘制。两种 RPK 首页均提供「设置」与可点击的刷新时间。设置中可查看连接状态、刷新车况，以及查看固件提供的应用版本号。标准屏另有主题和昼夜设置，双列空间充足且至少有两个车控时，可切换列表与网格。

标准屏先请求最高 288×144 的 PNG；手机可直接返回兼容图。高清分片、写入或显示失败时，设备会单独请求最高 160×80 的兼容图。两级都没有可用图时才显示内置领克车图，初次取图期间车控可直接使用。标准屏「设置 → 主题」可查看传输进度、保存结果或重新同步。短暂断线或切回前台后，重新核对手机选中的主题，再继续同一主题的分片。

## 验证范围

- 自动化覆盖正式 RPK 的资源、常见屏形和极窄屏、旧固件漏报、默认车图和动态背景绑定。
- Android 使用模拟器验证目标尺寸下的布局、离线缓存与部分混装主题协议。
- Vela 实际渲染和蓝牙通信仍需对应机型的真机确认。屏幕尺寸校验和协议回归只覆盖相应测试场景。
