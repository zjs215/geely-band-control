# 车控安装助手

把 `wrist-car-control-installer.apk` 安装到 Android 手机。「手机」安装口袋车控。「穿戴」可搜索或手动选择设备，手机会按设备匹配安装方式，再点「安装或更新」。助手检查项目 GitHub 的最新稳定版，按设备选包并校验 SHA-256；存在可用在线更新时展示该版本的更新内容，也可点击顶部状态栏或更新卡片弹窗查看完整说明。GitHub 不可用、版本早于内置包或校验失败时，使用内置包。安装结果会显示版本与来源。

打开助手时会自动检查 GitHub 稳定版。手机版直接读取系统中的已装版本。手环版使用按蓝牙地址保存的上次安装确认记录。手表版可使用上次成功连接的无线调试地址读取当前版本，也可在「无线调试设置」中点「读取手表版本」。读取不到手表版本或没有手环安装确认记录时，界面显示可用安装包版本。

## Android 手机

在「手机」页点「安装或更新」。首次使用时，安卓会要求允许此助手安装应用。开启后回到助手，按系统提示确认。安装完成后点「打开口袋车控」，可继续配置车况和腕上设备。

## Vela 手环和手表

| 设备 | 安装包 |
| --- | --- |
| 小米手环 8 Pro、9 Pro、小米手环 10 等直屏手环 | Lite RPK |
| 小米手环 10 Pro、其他 Vela 手表 | 普通 RPK |
| 小米 Watch 5 | 手表 APK |

助手识别名单内的蓝牙设备名。蓝牙名称无法确认时，可在「穿戴 → 切换」中手动选型号。RPK 直装使用 Vela V2 经典蓝牙，具体固件能否直装仍需验证。遇到不通的设备，可在「连接设置 → 保存 RPK 到手机」保存对应安装包，然后用 AstroBox 安装。

1. 在小米运动健康连接手环并同步一次。在「我的 → 关于」连续点击应用图标，按提示导出或迁移日志。ZIP 通常保存在「下载 → wearablelog」。
2. 首次按设备提示进入配对流程。10 Pro 可在「设置 → 我的设备 → 连接新手机」开启搜索。在助手的「穿戴」里搜索并选中设备，按系统提示确认配对。
3. 首次按助手提示授权 `wearablelog` 文件夹，或选择导出的 ZIP。助手按设备地址匹配日志中的 AuthKey，认证后通过该连接发送对应的 RPK。换绑后重新导出日志。
4. 下次直接点「安装或更新」。助手优先使用上次成功认证的蓝牙地址与连接方式。如果未能重连，安装按钮下方会提供「重试连接」和「搜索附近设备」。若直连通道被小米运动健康等现有连接占用导致回退通道断开，或重连失败，可使用「重新配对并连接」重置旧蓝牙配对并发起经典蓝牙配对（也可在「连接设置」中手动触发）。让手环靠近手机并亮屏，退出正在连接这只手环的其他应用后再试。「连接新手机」用于首次配对或确需重新配对的场景。

   如果先手动连接小米手环 10 Pro，助手在前台等待安装或准备安装包时会定时检查连接，最多等待 90 秒。开始发送安装请求前会停止检查。
5. 等待手环回执。若显示「已传完」，先在手环应用列表核对安装和版本，再打开小米运动健康恢复连接。

如果手环收完 RPK 后报告安装失败，助手会尝试读取设备上的腕上车控版本，并提供「保存 RPK 到手机」和日志导出。代码 1 表示设备侧安装失败。代码 2 表示校验失败。使用 AstroBox 对照时，请选择同一个 RPK 文件。

「连接设置」中可以选择已配对手环、导入单个 ZIP 或手填 AuthKey。也可以在手环页点「连接手环」确认已认证，再点「安装或更新」。[日志导出参考](https://github.com/HyperionD/minstall/tree/v0.2.0)

「连接设置 → 如何导出运动健康日志」提供完整步骤和打开小米运动健康的入口。导出后可授权日志目录，或在助手里选择刚生成的 ZIP。

「连接设置 → 检查系统蓝牙配对」可以进入安卓蓝牙设置。已有系统配对时，助手直接复用。配对已丢失时，重新连接会触发系统配对流程。设备返回的认证结果和系统蓝牙链路事件会写入诊断日志，可用于区分认证拒绝、RFCOMM 断开和安卓报告的蓝牙链路变化。

### 导出连接和传输日志

复现后点「连接设置 → 导出诊断日志」，或点断线提示下方的同名按钮。Android 10 及更新版本直接保存到「下载」，Android 9 通过系统文件选择器选位置，文件名为 `vela-diagnostics-*.txt`。保存成功后点「分享诊断日志」可打开安卓分享面板。日志区分一键安装和手动连接，按时间记录连接方式、认证、空闲断线、分片和回执。日志滚动保存在手机本地，关闭助手后仍可导出。文件记录手机型号和系统版本，排除 AuthKey、蓝牙地址、原始运动健康日志和传输内容。

日志在手机本地读取。助手保存目录的只读授权和上次选定的蓝牙地址，AuthKey 只保留在本次运行的内存中。覆盖安装沿用穿戴应用的原签名，Vela 端与手机端使用同包名、同证书的配套包。

## 小米 Watch 5

1. 在「穿戴」里选中小米 Watch 5。在手表上开启开发者选项和无线调试，把手机和手表连到同一 Wi-Fi。
2. 首次使用，在表上打开「使用配对码配对」。把该页面的 IP、配对端口和六位码填到助手，点「配对手表」。
3. 回到手表的无线调试首页，输入该页显示的**连接端口**，点「安装或更新」。助手通过无线 ADB 发送手表 APK 并回读包版本。
4. 助手会记住成功使用的地址和连接端口。下次在同一 Wi-Fi 且手表开启无线调试时，可以直接安装或更新。地址变化时在「无线调试设置」中更新。

手机在私有存储中加密保存自己的 ADB 配对身份。手表端可以通过无线调试页面移除已配对的助手。具体菜单和连接能力取决于手表固件。

## 构建

先准备版本目录中的 `pocket-car-control.apk`、`wrist-car-control.rpk`、`wrist-car-control-lite.rpk`、`wrist-car-control-watch.apk` 及对应的 `SHA256SUMS.txt`，然后从项目根目录运行。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\build-installer.ps1
```

`-PackageDirectory` 可指向保存这些文件的其他目录。脚本检查四个包的版本、目标和 SHA-256，然后构建、测试并输出 `artifacts/v0.3.2/wrist-car-control-installer.apk`。覆盖旧版需使用同一签名。蓝牙及无线安装流程需用对应真机核验。

手环路径参考 [minstall v0.2.0](https://github.com/HyperionD/minstall/tree/v0.2.0)。手表路径使用 [libadb-android-bc 3.5.1](https://github.com/osservatorionessuno/libadb-android-bc/tree/3.5.1)。
