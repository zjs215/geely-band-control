# 领克米家通知语音

通知桥接来自米家 `com.xiaomi.smarthome`。通知正文、展开正文或标题中的指令码必须完全匹配；冲突、过期或重复通知不触发控制。领克使用独立命名空间 `LYNKCO_V1`，品牌切换关闭语音及授权。

领克语音支持测试和三项切换，不需要手动标记动作方向。切换指令会点击当前官方卡片上的按钮，实际方向取决于车辆当前状态。车主已反馈 `LYNKCO_V1:LOCK_TOGGLE` 实车可用。

| 米家手动场景名 / 小爱说法 | 通知内容 | 执行条件 |
| --- | --- | --- |
| 领克测试 | LYNKCO_V1:TEST | 仅手机显示测试通知回执，无控车 |
| 领克切换车锁 | LYNKCO_V1:LOCK_TOGGLE | 免标记。点击唯一识别到的车锁按钮，可上锁或解锁 |
| 领克切换车窗 | LYNKCO_V1:WINDOW_TOGGLE | 免标记。点击唯一识别到的车窗按钮，可开窗或关窗 |
| 领克切换后备箱 | LYNKCO_V1:TRUNK_TOGGLE | 免标记。点击唯一识别到的后备箱按钮，可打开或关闭 |

先在米家智能页面新建「手动执行」场景，命名「领克测试」，添加向手机发送通知的动作，将通知内容完整设为 LYNKCO_V1:TEST，保存；在小爱语音控制/场景入口同步并允许语音执行（不同米家版本入口可能不同）。说「小爱同学，领克测试」，先验证伴侣测试回执。然后逐个建立表中场景，通知内容仅放对应指令码，场景名带领克避免与银河重名。米家若未提供手机通知动作或小爱不可发现该场景，应先处理该版本支持问题。

伴侣先选择领克、授予通知使用权并打开米家语音。添加官方卡片后先刷新车况。识别到多个同类按钮时，请在穿戴端手动选择。旧领克场景使用的 `LOCK`、`UNLOCK`、`WINDOW_VENT`、`WINDOW_OPEN`、`WINDOW_CLOSE` 已停用。改用切换码时，也请把口令改成「切换」，以免被误认为会执行固定方向。

开启允许车控和米家语音后，从米家收到有效控制通知会由手机直接派发，无需启动穿戴通信。穿戴手动操作仍在穿戴端确认一次，自动识别到的车锁或车窗可直接确认切换。伴侣只在同一卡片于 5 秒内出现与本次动作匹配的新官方弹窗时提交一次确认。未知动作、标题不匹配或过期时，仍交由车主在手机卡片上处理。回执表示指令已转交，最终状态以官方 App 与车辆为准。

发动机、升降温、天窗、寻车和充电口等功能未开放领克语音直发。

车主此次确认的是「切换车锁」语音场景。其他语音指令、车型覆盖和官方弹窗触发条件仍需分别核对。
